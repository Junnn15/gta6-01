SOLMAR HEAT — an original open-world crime game in three.js. Dario Cruz owes the Bay Crew $8,000; fixer Marta Reyes offers four missions that buy his freedom. Explore the sun-soaked coastal city of Solmar on foot and by car, steal cars, outrun the Solmar PD under a five-star wanted system, fight, and clear the debt across a courier job, a car boost, a timed getaway, and a bank heist.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
